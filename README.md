# Factorial Calculator in Python

A lightweight, robust Python module to calculate the factorial of a non-negative integer using recursion. 

---

## Features

* **Recursive Implementation:** Clear and concise recursive logic.
* **Input Validation:** Handles edge cases, invalid data types, and negative inputs cleanly.
* **Type Hints & Docstrings:** fully typed and documented for developer clarity.
